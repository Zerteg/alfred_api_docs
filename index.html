Документация API Альфреда

Для просмотра схем и примеров открой Swagger UI с подключением к интернету или скачай OpenAPI YAML.

  • GET /trips/{tripId}/planПолучить общий план
  • POST /trips/{tripId}/flight-segmentsДобавить рейс к поездке
  • GET /trips/{tripId}/segments/{segmentId}/alternativesПолучить альтернативы для сегмента
  • POST /trips/{tripId}/plan-changesПринять предложенный вариант
  • GET /trips/{tripId}/plan-changes/{changeId}Получить состояние изменения
  • GET /notificationsПолучить входящие уведомления
  • PUT /notifications/{notificationId}/readОтметить уведомление прочитанным
  • POST /integrations/flight-status/{source}Принять событие о рейсе
